SHOPMAX99 FULL PROJECT V11

Major changes:
- Seller registration no longer requires Admin approval; new seller accounts are active immediately.
- Seller product listing no longer requires Admin approval; valid listings are published immediately.
- Seller-owned product edits publish directly after pricing validation.
- Pricing categories: Rs 99, 199, 299, 399, 499, 599, 699, 799, 899, 999, and Above Rs 1000.
- Customer selling price automatically maps to the nearest upper pricing category. Example: Rs 250 -> Rs 299 category.
- Seller price cap: Rs 70 for Rs 99 category; Rs 160 for Rs 199 category; higher categories use the platform-fee rule.
- Platform fee displayed to sellers: Rs 29 or 12%, whichever is higher.
- Home page now has separate pricing categories and sample items in every category.
- Seller Support and Customer Support can edit structured seller/customer data and product data as drafts.
- Support edits are not applied live; they create Admin approval requests with Before Edit and After Edit snapshots.
- Admin can review and Accept & Apply or Reject. Accepted changes automatically update the live record.
- Cache-busting version updated to 20260927-11.
